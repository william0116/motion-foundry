# Motion Foundry · 动效工坊

静态 HTML/CSS/JavaScript，浏览器 Canvas 2D 渲染，内置 gifenc 1.0.3 编码器；无外部 CDN、外部字体、AI 请求或用户素材上传。需要通过 HTTP 服务访问，不能直接双击 file:// 文件加载 ES Modules。

本地：在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/ 。

自检页面：`/qa.html`，点击运行，覆盖当前 108 个模板、三个画幅、五个时间点、确定性渲染、PNG 解码 Alpha、48 帧 ZIP CRC、取消及输入校验。自检不替代目标剪辑软件验收。

导出真实 PNG 序列 ZIP、当前帧 PNG 和循环 GIF。GIF 可选透明（1 位 Alpha）、白底、黑底；不能保留 PNG 的完整半透明效果。透明 MOV、AI、团队共享尚未实现。页面刷新丢失当前编辑；收藏/最近使用仅本浏览器保存。使用系统中文字体，不承诺跨系统像素完全一致。

核心文件：data.js 定义模板与校验，renderer.js 负责确定性绘制，exporter.js 负责 PNG 和无压缩 ZIP 容器，gif-exporter.js 负责 GIF，workbench.js 负责交互。

## 本地增补 v0.5：GIF 导出（2026-09-10）

沿用 Sites 网站构建 Skill 保留静态结构和现有导出交互，仅更新本地版，未发布线上。

- 在「透明导出」窗口增加「GIF 动图」，沿用当前模板、文案、配色、画幅、时长和本地图片，自动无限循环。
- GIF 默认短边 480px / 15 fps；可选短边 360 / 480 / 720px，10 / 15 / 20 fps。PNG 的 720 / 1080p 和 24 / 25 / 30 fps 不变；两种格式分别记住当前窗口内的设置。
- 支持透明、白底、黑底。透明模式把原始 Alpha < 128 的像素设为透明，其余设为不透明；每帧最多 256 色，不能代替 PNG 的完整 Alpha。白底 / 黑底将柔边与淡入淡出合成到所选底色，预览棋盘格、安全区不写入。
- 每帧保留独立颜色表和清除背景处置，避免移动元素拖影及黑色像素误删。按累计百分之一秒分配帧延迟，15 fps 不产生总时长漂移。
- 编码全程在浏览器本地进行，支持进度、取消、错误后重试及下载备用链接；限制大任务和超 80 MB 的编码结果，防止失控占用内存。
- 内置 gifenc 1.0.3 官方 ESM，许可证、来源、版本和校验值见 `dist/vendor/gifenc/`。无需 CDN 或安装依赖。
