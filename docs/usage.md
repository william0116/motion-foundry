# 使用与导出指南

## 1. 选择模板

按分类、合集或用途关键词筛选模板。默认画幅筛选只影响模板列表，每个模板仍能切换横屏、竖屏和方形。悬停卡片查看动态效果，点击后在右侧调整。

预览可收起，留出更多编辑空间；需要检查细节时使用“放大”。深色、浅色和棋盘格只帮助观察透明边缘，不改变导出背景。

## 2. 替换内容

不同模板可能开放主标题、辅助文字、小标签、正文、数据或图片。请以字段旁的限制和错误提示为准。

- 图表数据使用每行一个 `名称:数值`，也接受中文冒号。当前不支持负数，数据条数与数值上限由模板校验。
- 清单和流程每行一项；版式有行数限制，不通过堆叠长文本来模拟多页内容。
- 图片支持 PNG、JPEG、WebP，单张不超过 10 MB、2400 万像素。不同版式可能居中裁切；人物剪影效果需要已经去底的图片，不提供自动抠图。
- 图片窗口和人物小窗不是视频上传功能。透明窗口需要在剪辑软件中叠入原片。
- 时长可选 2、3、5 秒；动感、尺寸和位置是模板参数，不是自由关键帧时间线。全画面转场不使用位置、尺寸调节。

七种配色只影响当前动画，不会将整个模板库变成品牌主题。早期基础模板主要使用方案强调色，卡片与扩展模板使用更完整的色板。

## 3. 检查画面

拖动进度查看入场、中段与出场。尤其检查长中文、最大数据项、图片裁切，以及不同背景下的阴影和光晕。参考安全区不是平台审核保证；发布前仍要检查实际播放器上的按钮、标题和字幕遮挡。

刷新页面会丢失当前编辑内容和图片。收藏与最近使用仅保存在当前浏览器，不会同步到其他设备。

## 4. 选择导出格式

### PNG 单帧

导出当前预览位置的一张 RGBA 图片。适合封面元素、静态叠加和画面确认。

### PNG 序列 ZIP

透明视频叠加优先使用此格式。解压后包含：

```text
frames/
  frame_00000.png
  frame_00001.png
  ...
manifest.json
README.txt
```

`manifest.json` 记录模板 ID、尺寸、帧率、时长和编辑参数，但不是可重新打开的工程文件，也不包含源图片。将第一张 PNG 以“图片序列”导入支持此功能的软件，设置与导出一致的素材帧率，再叠加到主视频上方。不要把每帧当作默认数秒的独立静态照片。

不是每款剪辑软件都支持相同的序列导入方式，请先用两秒素材验证。项目不提供剪映、Premiere 或 AE 的自动导入接口。

### GIF

默认短边 480 px、15 fps，循环播放；可选择透明、白底或黑底。

GIF 每帧至多 256 色，没有连续 Alpha。透明模式下，Alpha 小于 128 的像素被设为全透明，其余可见；阴影和细边缘可能丢失。白底和黑底模式先合成底色，通常更适合包含光晕的分享预览，但不能作为透明素材使用。

较高分辨率和帧率会明显增加编码时间与内存。当前 GIF 编码有总像素预算及 80 MB 大小限制，超限会报错；可降低分辨率、帧率或时长后重试。

## 常见问题

**为什么“透明”导出后仍有卡片底色？**

卡片面板属于动画内容。透明指画布中未绘制的部分，不能自动去掉设计本身的底色。

**为什么两台电脑的字体有些不同？**

项目没有在线字体或字体包，依赖系统字体回退。需要一致的品牌字体时，先确认授权，再自行接入并测试排版。

**为什么转场没有自动切换我的视频？**

这里生成的是图形覆盖层。将它覆盖到剪切点上，在动画中点完全遮住画面时切换底层视频；应用本身不编辑原片。

**导出卡住或失败怎么办？**

先取消，降低分辨率或帧率，再重试。保留页面中的错误信息；如持续出现，请按[贡献指南](../CONTRIBUTING.md)提供参数和复现步骤。不要通过公开客户原片来报告问题。
